# 插件边界

来源插件输出标准内容事件，包含外部 ID、内容版本、来源、观测时间及可用的发布时间。来源首次建立完整基线。

模型适配器接收消息与文件工具定义，返回模型消息、工具调用和用量。运行器控制权限、步数、取消和产物校验。

平台适配器负责接入配置、扫码或鉴权、必要的消息接收、会话上下文和真实发送。`channels.py` 的目录登记实现状态，未实现项不允许创建。

当前扩展为内部注册和代码模块，尚无远程插件安装或热加载机制。新增平台必须提供实际配置结构与接入生命周期，并明确主动发送限制。

格式渲染与消息分片属于投递层。同一处理结果可用于多个平台，只有不同工作区或不同有效处理配置才产生额外模型任务。
