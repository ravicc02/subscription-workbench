# 单篇新闻整理规则

## 输入与筛选

读取本次事件 JSON、`docs/sources.md` 的范围与分类及 `article.text_path` 指定的原文，只处理这一篇。
RSS 标题与关键词只用于发现候选，须阅读现有正文确认与国际黄金、白银、原油、外汇直盘、交叉盘，或国际时政、地缘冲突、政策与选举直接相关。
时政类订阅含非时政内容：来源默认分类只是候选，须按公共影响、政策变化、外交、冲突和选举的实质进展判断。体育、娱乐、生活方式、纯商业推广和单一个人案件跳过。
不读取整批索引选稿，不扩大时间窗口补旧闻，不搜索其他类别，不为每个品种或议题凑条数。
不相关或有效依据不足时，在事件的 `outputs.note` 记录原因，最终返回 `SKIP: 原因`。

正文文件和原始链接是依据。`full_text` 表示已提取正文，仍须检查是否有明显缺漏。
`partial_text`、`summary_only`、`headline_only`、`blocked` 保留实际含义；只有标题或被阻止的页面不生成正文摘要。
来源摘要可以降级使用，输出必须带 `【来源摘要】`；部分正文带 `【部分正文】`，不冒充全文。
官方公告、来源报道、作者观点和 Agent 推断分别表达，不能因来源知名就将预测写成事实。
时政内容须区分已确认事实、当事方声明、媒体报道和 Agent 推断，并标明消息或观点主体。
香港电台等来源的正文容器内是裸文本加 `<br>` 换行，段落可能很短；按实际段落编号引用，不合并成一段再引用。

## 单篇整理稿

严格写入事件的 `outputs.processed`，不自选批次或文件名。至少保留：

```text
事件编号：本次 job_id
标题：准确的中文标题
类别：一个主要类别，可列次要关联品种
来源：实际来源名称
发布时间：原文时间与时区；无法确认则写未知
采集时间：事件原文元数据中的实际采集时间
原文链接：本篇真实文章地址
原文文件：article.text_path 中相对工作区的完整路径
正文范围：全文／部分正文／来源摘要

事实摘要：
核对后的关键事实、数值及必要背景，约 80～150 字。

原文观点：
机构或作者在原文中的明确判断，注明主体。

品种关联与判断：
本篇直接涉及的品种、可能影响、自己的推断及其条件。
（时政类改为「事件关联与判断」：本篇涉及的当事方、议题、可能影响、自己的推断及其条件。）

证据定位：
引用原文的 P001、P002 等段落编号；表格注明表头、对应行与字段。
```

没有原文观点或关联依据时写“未提供”或“依据不足”。不复制未读正文的摘要冒充阅读结果。
处理持仓或产业表格时核对列名、单位、报告时点与变化基期，不能将不同列或不同报告期混为一谈。

## 分析字段

金融品种写“品种走势分析”，时政类别写“事件影响分析”。按本篇主要类别只写其中一个。

### 品种走势分析

当前事件只提供文件读写工具，没有独立行情源。分析明确写“新闻因素分析，未独立核验实时行情”。
原文报告的行情可注明“原文截至某时点”，保留数值、单位、日期及口径，不写成 Agent 已核验的实时价格。
严格区分现货、期货、连续合约、日度参考汇率和盘中报价，不凭模型记忆补数。

区分来源观点与 Agent 判断，每条判断需有本篇整理稿支持，使用可能、条件和不确定性表达。
不能仅凭同时发生就宣称因果，不编造目标价、技术位或预测命中率。
外汇按货币对方向判断，例如 USD/CAD 下行不能写成加元下跌。
交叉盘如果没有直接报道，关联分析须明确为推断，并说明涉及的两种货币及依据。

### 事件影响分析

说明事件可能的后续影响、触发条件和不确定性；每条判断需有本篇整理稿支持。
不编造时间表、伤亡数字、军事结论或外交结果；原文未确认的只写为报道或猜测。
区分事实、当事方声明、媒体报道和 Agent 推断，并标明主体。
不把单一事件夸大为确定性转折，也不预测具体结果。

## 输出与回溯

整理后读取 `docs/news-flash-template.md`，将本篇“新消息快讯”写入 `outputs.report`，执行记录写入 `outputs.note`。
记录包含事件编号、原文路径、整理稿路径、快讯路径、执行阶段、跳过原因或信息限制。
每条摘要能追溯到原文段落或表格，每条走势或影响判断能追溯到整理稿；快讯保留本次真实文章链接。
不创建全量索引、多品种汇总或额外文件。正常完成时保存三个指定输出，最终回复原样返回快讯，由插件投递。
